# AI Side Hustles - Blog Site

A Next.js 15 blog about making money with AI tools. Built with TypeScript, Tailwind CSS, and MDX.

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## 📝 Adding Blog Posts

Create `.mdx` files in `content/posts/`:

```mdx
---
title: "Your Post Title"
description: "SEO description"
date: "2026-02-13"
category: "Tools"
---

Your content here...
```

## 📊 Setup Analytics & AdSense

1. Copy `.env.example` to `.env.local`
2. Add your IDs:

```env
NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX
NEXT_PUBLIC_ADSENSE_ID=ca-pub-XXXXXXXXXXXXXXXX
```

Get these from:
- [Google Analytics](https://analytics.google.com)
- [Google AdSense](https://adsense.google.com)

## 🚀 Deploy to Vercel

1. Push to GitHub
2. Import to [Vercel](https://vercel.com)
3. Add environment variables
4. Deploy

## 📁 Structure

```
app/
  page.tsx              # Homepage
  blog/
    page.tsx            # Blog listing
    [slug]/page.tsx     # Blog post
content/posts/          # Blog posts (.mdx)
components/             # React components
```
