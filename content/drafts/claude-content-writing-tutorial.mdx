## The Claude Content Writing Process

### Phase 1: Research & Outline (10 minutes)

**Step 1: Topic Research**

**Prompt:**
```
I'm writing a blog post about [topic] for [target audience].

What are the top 10 questions people ask about this topic?
What are the main pain points?
What unique angle should I take?
```

**Claude's response will give you:**
- Reader questions to answer
- Content structure ideas
- Unique positioning

**Step 2: Competitor Analysis**

**Prompt:**
```
I found these top-ranking articles on [topic]:

1. [Article 1 main points]
2. [Article 2 main points]
3. [Article 3 main points]

What are they missing?
What could I do better or differently?
Suggest 3 unique angles I could take.
```

**Step 3: Create Outline**

**Prompt:**
```
Create a detailed blog post outline for:

Topic: [Your topic]
Target audience: [Who is this for]
Length: [Word count]
Goal: [What should reader learn/do]

Include:
- Compelling headline options (5 variations)
- Introduction hook
- 5-7 main sections with subsections
- Examples to include in each section
- Conclusion with clear CTA

Make it [tone: conversational/professional/casual]
```

**Claude excels at outlines.** They're detailed and logical.

### Phase 2: Writing the Content (30-40 minutes)

**The secret:** Write section by section, not all at once.

**Why:**
- Better quality per section
- More control
- Easier to edit
- Less repetition

#### Section-by-Section Method:

**Prompt for Introduction:**
```
Write an introduction for this blog post:

Title: [Your title]
Outline: [Paste full outline]
Target audience: [Description]

The introduction should:
- Open with a hook (question, stat, or bold statement)
- Explain why this matters to the reader
- Preview what they'll learn
- Set the tone for the article
- Length: 150-200 words
- Tone: [conversational/professional/engaging]

Make it punchy and human-sounding. No AI clichés like
"delve," "landscape," or "it's worth noting."
```

**Prompt for Main Sections:**
```
Write section 3 from this outline:

[Paste the specific section from outline]

Include:
- 2-3 specific, real examples
- Actionable takeaways
- Data or statistics (if relevant)
- Subheadings to break up text
- Length: 250-350 words
- Tone: [your brand voice]

Avoid:
- Generic advice
- AI clichés
- Passive voice
- Overly formal language
```

**Repeat for each section.**

**Prompt for Conclusion:**
```
Write a conclusion for this blog post:

Topic: [Topic]
Main points covered: [Summarize 3-4 key takeaways]
Target audience: [Who]

The conclusion should:
- Summarize key takeaways (briefly)
- Reinforce main benefit
- Clear call-to-action
- Leave reader motivated
- Length: 150-200 words
- Tone: [empowering/helpful/direct]

End strong, not generic.
```

**Time breakdown:**
- Introduction: 5 min
- 6 main sections: 30 min (5 min each)
- Conclusion: 5 min
- **Total:** 40 minutes for 1,500-word article

### Phase 3: Editing (20-30 minutes)

**Claude can edit itself, but you need to guide it.**

#### Edit Pass 1: Remove AI Language

**Prompt:**
```
Review this content and remove AI-sounding language:

[Paste content]

Specifically remove or replace:
- "Delve," "landscape," "realm," "unlock"
- "It's worth noting that"
- "In today's digital age/landscape/world"
- Overly formal transitions
- Generic conclusions

Make it sound like a human wrote it.
Keep the same information and structure.
```

#### Edit Pass 2: Add Personality

**Prompt:**
```
Rewrite this to add more personality:

[Paste content]

Make it:
- More conversational
- Include "you" and "I" language
- Add occasional sentence fragments (for emphasis)
- Vary sentence length
- Include rhetorical questions
- Slightly more casual but still professional

Don't change the facts or structure.
```

#### Edit Pass 3: Improve Readability

**Prompt:**
```
Improve the readability of this section:

[Paste content]

- Shorten complex sentences
- Break up long paragraphs (max 3-4 sentences each)
- Add bullet points where appropriate
- Bold key phrases
- Make it scannable

Target reading level: Grade 8-10
```

#### Edit Pass 4: Fact Check

**Important:** Claude can hallucinate facts.

**Prompt:**
```
Review this content for accuracy:

[Paste content]

Flag:
- Any statistics or data (I'll verify)
- Specific claims that need sources
- Dates or timeline information
- Technical details

Don't change content, just flag what to verify.
```

**Then manually check flagged items.**

### Phase 4: Final Polish (10 minutes)

**Step 1:** Paste into Grammarly
- Fix grammar errors
- Reduce passive voice
- Check clarity

**Step 2:** Read aloud
- Catches awkward phrasing
- Ensures natural flow

**Step 3:** Final Claude pass

**Prompt:**
```
Final proofread of this article:

[Paste full article]

Check for:
- Repetitive words or phrases
- Inconsistent tone
- Logical flow between sections
- Any remaining AI language
- Missing transitions

Suggest improvements.
```

## Advanced Claude Techniques

### Technique 1: Brand Voice Training

**Create a custom instruction:**

**Prompt:**
```
I need you to write in my brand voice.

Here are 3 examples of my writing:

[Paste 300-500 words of your actual writing]

Analyze my:
- Sentence structure
- Vocabulary choices
- Tone and personality
- Use of examples
- How I address readers

From now on, match this style when you write for me.

Confirm you understand by rewriting this paragraph
in my voice: [Paste a generic paragraph]
```

**Claude will adapt to your voice.**

### Technique 2: The "Anti-AI" Prompt

**Add this to every writing prompt:**

```
Critical rules:
- No words: delve, landscape, realm, unlock, leverage, revolutionize
- No phrases: "it's worth noting," "in today's world," "dive deep"
- Use contractions (I'm, you're, don't)
- Vary sentence length dramatically
- Include sentence fragments. Like this.
- Sound human, not corporate
```

**This makes Claude 80% more human-sounding.**

### Technique 3: Iterative Improvement

**Instead of one prompt, iterate:**

**Round 1:**
```
"Write an introduction to [topic]"
```

**Round 2:**
```
"Make it more engaging and less formal"
```

**Round 3:**
```
"Add a surprising stat or question as the hook"
```

**Result:** Much better than trying to get it perfect in one prompt.

### Technique 4: Example-Based Writing

**Show, don't tell:**

**Weak prompt:**
```
"Write in a conversational tone"
```

**Strong prompt:**
```
"Write like this example:

[Paste 200 words of your ideal style]

Match the tone, structure, and personality."
```

**Claude learns better from examples than descriptions.**

### Technique 5: The Comparison Method

**Prompt:**
```
Here's a draft I wrote:

[Your draft]

Rewrite it to:
- Keep my ideas and examples
- Improve clarity and flow
- Fix awkward phrasing
- Maintain my voice

Show me before and after for each paragraph.
```

**Great for editing your own writing with Claude's help.**

## Content Types & Specific Prompts

### Blog Posts (1,000-1,500 words)

**Full prompt template:**
```
Write a [word count] blog post.

Title: [Title]
Audience: [Specific description]
Goal: [What should reader do/learn/feel]
Tone: [Conversational/professional/educational]

Structure:
- Hook (surprising fact or question)
- Intro (150 words): Problem + why it matters
- [Number] main sections (250-300 words each)
- Conclusion with CTA (150 words)

Include:
- Real examples (specific, not generic)
- Actionable tips
- Subheadings every 250-300 words
- Bullet points where appropriate

Avoid AI language. Write like a human expert talking to a friend.
```

### LinkedIn Posts (150-300 words)

**Prompt:**
```
Write a LinkedIn post about [topic].

Hook: [Start with a bold statement or question]
Format:
- Short opening paragraph (2-3 sentences)
- 3-5 bullet points or short paragraphs
- Closing thought with CTA

Tone: Professional but conversational
Length: 200-250 words

Include: Line breaks for readability
Avoid: Corporate jargon, hashtag spam
```

### Email Newsletters

**Prompt:**
```
Write an email newsletter for [audience].

Subject line: [Provide 3 options]

Email structure:
- Personal opening (2-3 sentences)
- Main content (250-350 words)
  Topic: [Your topic]
  Include: [Key points]
- Quick tip or resource
- CTA: [What you want them to do]
- Friendly sign-off

Tone: Like writing to a friend
Make it: Skimmable, valuable, not salesy
```

### Social Media Captions

**Prompt:**
```
Write 5 Instagram captions for a [business type].

Topic: [Theme]
Audience: [Target]
Length: 100-150 words each

For each caption:
- Hook in first line
- Value/entertainment/education in body
- CTA or question at end
- 5 relevant hashtags
- Moderate emoji use

Make them varied in style and topic.
```

### Product Descriptions

**Prompt:**
```
Write a product description for:

Product: [Name]
Features: [List key features]
Benefits: [How it helps customer]
Target customer: [Who needs this]
Price point: [Range]

Structure:
- Compelling headline
- Opening paragraph (emotional benefit)
- Feature bullets with benefits
- Social proof element (how many sold, reviews, etc.)
- Clear CTA

Length: 150-200 words
Tone: [Compelling/luxurious/friendly/professional]
```

### Case Studies

**Prompt:**
```
Write a case study based on:

Client: [Industry/type]
Challenge: [Their problem]
Solution: [What we did]
Results: [Specific outcomes]

Structure:
- Title (compelling, outcome-focused)
- Client background (50 words)
- The challenge (100 words)
- Our approach (150 words)
- Results (100 words with metrics)
- Client testimonial (quote)
- Key takeaways (bullets)

Total length: 500-700 words
Tone: Professional but storytelling
```

## Common Claude Mistakes (And Fixes)

### Mistake 1: Too Verbose

**Problem:** Claude writes 500 words when 250 would work.

**Fix:**
```
"Rewrite this to be 40% shorter. Keep key points,
remove fluff."
```

### Mistake 2: Too Formal

**Problem:** Sounds like a corporate manual.

**Fix:**
```
"Make this sound like a conversation, not a textbook.
Use contractions, shorter sentences, and casual language."
```

### Mistake 3: Generic Examples

**Problem:** "A business might..." instead of specific examples.

**Fix:**
```
"Replace all generic examples with specific, real examples.
Instead of 'a business,' use 'a local coffee shop' or
'a SaaS startup.'"
```

### Mistake 4: Repetitive Phrasing

**Problem:** Starts every paragraph the same way.

**Fix:**
```
"Vary the sentence structure. Don't start paragraphs
the same way. Mix short and long sentences."
```

### Mistake 5: Weak Conclusions

**Problem:** Generic "In conclusion..." endings.

**Fix:**
```
"Rewrite the conclusion. Make it actionable and
motivating. Give clear next steps, not a summary."
```
